Entry for the make.fun **Dad Joke Showdown** — one original dad joke, delivered straight-faced, in a single line. The program writes the joke to `entry.txt`; a hard guard refuses to run if the line ever exceeds 200 characters.

## Run

```sh
node main.ts
```

Set `MAKEFUN_OUTPUT_DIR` to choose where `entry.txt` is written (defaults to `/output`).

## The entry

> My wife told me to stop making cheese puns, so I said 'brie serious' — and now she's really grated at me.
